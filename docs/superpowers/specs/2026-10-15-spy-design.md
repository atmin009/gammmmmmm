# วงลับ — agreed design
Thai mobile-first in-person spy word game. Host configures 3–30 players, 1 to N-1 spies, category and 1–10 clue rounds. Separate unguessable player links show only that player's word, never their role. Host can join by opening a player link. Host link controls the room but cannot inspect roles before reveal. All players keep the same assignment throughout clue rounds. After final round, everyone votes once for someone else, then results reveal automatically when all votes arrive. Ties display all tied players; results show every spy, both words and vote counts without inventing a win rule. New games reuse links, shuffle assignments and clear votes. Lobby names must be set before start. D1 persists shared state; version-checked updates prevent simultaneous votes or host actions overwriting state. Browser polls every 2 seconds. Tokens stay in URL fragments and Authorization headers. No word list or room secrets in client bundles. Room expires in 24 hours. Sites hosting starts private as required; team access needs a supported audience change.
