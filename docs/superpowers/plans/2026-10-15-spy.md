# Spy Circle Implementation Plan
> **For agentic workers:** Use superpowers:executing-plans inline.
**Goal:** Play the agreed Thai spy game across phones.
**Architecture:** Vinext React client, server API, D1 versioned room JSON. Pure game reducer filters all views.
**Tech Stack:** React, TypeScript, Cloudflare D1, Node tests.
**Spec:** docs/superpowers/specs/2026-10-15-spy-design.md
## Global Constraints
Thai responsive UI; 3–30 players; 1–10 clue rounds; 1..N-1 spies; private player words; same links between games; server authority.
## Review Focus
- Concurrent votes: CAS retries retain each player's vote.
- Replayed actions: expected version rejects stale host actions.
- Hidden roles: host and player projections cannot leak other words or spy markers.
- Invalid configuration and tokens: reject on server.
- Refresh/restart: preserve links, clear prior votes and hide prior words.
